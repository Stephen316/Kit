# Generation 19000 rectangle width and height

`WriteRectDims` continues the [line collection](RectangleLines.md) through the two local driving distances. It takes the ordered local corners, allocated dimension IDs and driving lengths in millimetres. A length must select one and only one edge incident on the anchored corner. The codec emits the native system value in metres and returns each allocated distance object to the caller for later display ownership.

## Native field ownership

These preferred virtual addresses refer to the `34.4.1.1011` `sldmodu.dll` [pin used for the corner writer](RectangleCorners.md).

| Scope | Native owner |
| --- | --- |
| Group counts | The `sgSketch` serializer's non-line geometry groups close with eleven dword counts. The value-dimension helper at `0x4c59efa0` reads the G1 and G2 short counts at `0x4c59f203` and `0x4c59f505`. The ordinary rectangle has empty geometry and G1 groups and two G2 distances. [Typed count replay](../../../src/convert/adapters/solidworks/Sketch/Relations.py) |
| Distance and parameter | The `sgPntPntDist` slot-5 body at `0x4c59d120` calls the value-dimension base at `0x4c59d13f`. The base calls the ordinary dimension serializer at `0x4c59cb41` and emits the absent transform selector at `0x4c59cb61`. Each distance allocates its own `moLengthParameter_c`, whose store at `0x4c175bd0` delegates to the native node then writes the `Value` scalar. The existing [typed length writer](BlindDepth.md) shares that field layout. |
| Operands and return | The non-DB stores at `0x4c59d214` and `0x4c59d220` write local point handles. The distance serializer writes `ArcDimType0`, `ArcDimType1`, `Quadrant` and `Chamfer` followed by its absent `ActivePlane` and zero `Direction`. The supported branch uses `(1,1,1,0)` for the four shorts. |

In all 14 pinned saves, the pre-dimension counts start at byte 7370, the first distance tag at 7418 and the second at 7611. The value group returns at 7767. The first distance and its parameter define their classes. The second allocates independent objects under those classes. Both distances allocate two new point handles and owned name objects. The archive counter advances by twelve.

The licensed dimension rows confirm 28 active driving values and owners. Width reads 0.040 or 0.041 metres and height 0.020 or 0.023 metres. The inch-display files retain the same system lengths. XY width selects `(0,3)` and height `(0,2)`. The YZ controls exchange the second operand because the local principal axes differ. Both lengths are separately bound to the anchored profile. Native slot 0 and the actual width or height edge determine their handles.
