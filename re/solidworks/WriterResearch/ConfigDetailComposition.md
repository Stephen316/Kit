# Composed Config-0 saved detail

`WriteConfigDetail` appends the complete generation-19000 saved detail interval to the live part archive after the relation manager. The caller supplies the typed settings for the [detail start](ConfigDetailOpening.md), [dimension styles](ConfigDimensionStyles.md), [annotations](ConfigAnnotations.md), [tables](ConfigTables.md), [drawing labels](ConfigLabels.md), [finish and notes](ConfigFinishNote.md), [weld and tolerance](ConfigWeldTolerance.md), and [detail return](ConfigDetailReturn.md). That last writer includes the empty shared parameter array immediately before the environment.

The dimension styles register nine length formatter objects against the class established by the earlier units table. All other detail stages leave the map unchanged. The function uses the caller's writer for the entire interval. A validation failure restores the earlier bytes and both archive maps.
