# Standard Config-0 views

The ordinary generation-19000 configuration writes an empty `suObList`, ten standard `moView_c` objects, an empty feature color table and the model settings around it. The first name is `*Normal To` and the last is `*Dimetric`. The list allocates two slots, the views allocate eleven and the schema-zero `moFeatColorTab_c` allocates two. On all 14 pinned P01 and P03 saves, the group is 2,079 bytes and ends immediately before `moSketchBlockMgr_c`. It moves the map from 79 to 94 in P01 and from 83 to 98 in P03.

The installed `sldmodu.dll` from SOLIDWORKS `34.4.1.1011` has SHA-256 `2201734ebe0106efde5a93e306067b4b5e2fdb0ba70bf38ce9a59242b283cb99`. `setDocumentDefaultViews` at `0x4c033630` allocates ten named view objects. `resetStdViews` at `0x4c0301b0` initializes their transforms through `mg_RotationQuaternion`, quaternion multiplication and `quatToMatrix`. Its angle literals include the quarter turn at `0x4ce0d688` and the oblique angles at `0x4d0c6110–0x4d0c6140`. The research writer composes equivalent yaw and pitch matrices using those constants. Across the pinned files, each generated element differs from the saved element by at most `1.12e-16`. Normal To and Front omit the identity rotation. All ten leave the second transform at identity.

`moView_c::Serialize` at `0x4c22a1d0` writes the name, then both `mgXform_c::save` calls at `0x4c22a22a` and `0x4c22a23a`. The ordinary constructor at `0x4c14d780` supplies its default state. The serializer saves `ViewId` from `+0x360`, perspective factor from `+0x378`, and section transparency from `+0x3b8`. The three optional view collections remain empty.

The model serializer loops over ten view pointers at `0x4c23220a–0x4c232240`. It emits the frozen byte at `+0xd2c`, browser split at `+0xce8`, and the word at `+0xcec` before calling the color-table archive operator at `0x4c23227d`. The color table declares schema 0 in the `sldmfcu.dll` runtime class at `0x3ce7b490`. The return stores the next display object ID from `+0xd44`, an empty section-light collection from `+0xdb8`, and the word at `+0xd48`. `WriteSavedViews` covers the observed default values for these model settings.

The source-to-range digest map hashes to `56fbc3f5a09c81918a8702d5598172b3c4650aba233901e3ddf293073abee395`. The hosted check generates the default table, compares all bytes outside the eight rotations and checks both complete allocation maps. The rotation doubles use a `4e-16` absolute element tolerance.
