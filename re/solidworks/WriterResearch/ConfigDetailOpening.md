# Config-0 detail opening

The configuration model files an empty inline model array and its document detail settings after the ghost and relation managers that follow the [atom manager](ConfigAtomManager.md). `WriteDetailOpening` constructs the first 116 bytes after the relation manager for generation 19000. `WritePlainCharFormat` constructs the distinct inline character format. `WriteDetailStart` composes both helpers with the other detail and dimension settings in the same inline interval.

The opening SHA-256 is `6bfbf8c53ada99530d571a98d60420d1de32ac5426445871d629c33c5693aaec`. The full interval has SHA-256 `5c6c9dd24a62dd2a7d4c15bc9b65b8ac1730735918de2108bfa55fba68cc72d4`. Its replay digest `49e99ba22e662e41ba7895895cad5f14f5095039430f1b755492030b0ca00dd7` covers compact JSON rows keyed by the source SHA-256 and carrying the subrecord and composed hashes, the independent detail return and the inherited next slot.
