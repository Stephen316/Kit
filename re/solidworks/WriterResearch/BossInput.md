# Logical input for an ordinary SOLIDWORKS boss

`BossInput.ProjectBoss(CadDocument)` derives the logical inputs for generation-19000 research composition. It calls the shared feature-history and retained-data checks. Its output contains the selected sketch, original feature and parameter IDs, one body and configuration, the placement, native-local creation slots and a signed depth. It can supply the corner and line operands to the assembled [resolved profile and boss](BossResolve.md). It carries no archive, presentation, saved timestamp or kernel marker state.

## Supported contract

- One metric standalone part with one active configuration, one principal datum, one reference sketch and one directly consuming `DistanceExtrude`. The operation creates the only body. The datum has no face link or offset parameter.
- The two captured principal placements use zero translation and the Front basis `(+X,+Y,+Z)` or Right basis `(−Z,+Y,+X)`. Front width uses local +X and height uses local +Y. Right width uses local +Y and height uses local −X. Physical roles are read from their anchored dimension operands and checked against the length.
- The declared closed loop contains four free perimeter lines with one coincidence per corner. A fifth coincidence anchors a corner to its distinct fixed construction point. Each line has the correct horizontal or vertical relation. The logical output retains source-side operand order alongside fresh target-local edge IDs `1:(0,3)`, `2:(0,2)`, `3:(2,1)`, `4:(3,1)`. Target point slots are anchor, opposite corner, local-Y endpoint and local-X endpoint. Shared corners absorb the four endpoint joins. The separate origin remains a constraint.
- The `width_mm` and `height_mm` bindings are independent driving lengths on the reference sketch feature. The boss has one separate named driving length. The input's source-signed neutral value determines the native physical magnitude, reversal and axial limits; the logical DTO retains that original signed value. Length parameters may be expressed in mm or cm. The target's depth parameter has positive magnitude and the end stores the reversal.

The research projection refuses extra history, retained records, independent geometry payloads, unsupported material or configuration state, extra selections, a missing or ambiguous loop, nonrectangular or mirrored placements outside the witnessed signs, duplicate or mismatched operands, expression-driven sizes, and side, start or taper controls beyond the one-sided blind end. The current downstream dimension constructor selects its recorded incident edge by distinct magnitude, so this projection also refuses square profiles. It uses only one fixed origin surrogate and four line entities, with explicit endpoint coincidences.
