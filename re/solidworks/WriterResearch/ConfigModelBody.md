# Configuration model settings and hatch

`WriteModelBody` resumes [reference-plane appearance](ConfigModelView.md) at the first model bounding-box selector. It writes the bounded model settings and cosmetic update state, files a null 3D PDF publish cache, and allocates the section hatch. The enclosing archive remains ready for the following `moMaterial_c` definition. The box, settings, geometry stamp, cosmetic update entries and hatch presentation have separate inputs.

## Replay

```sh
python re/solidworks/WriterResearch/VerifyConfigBody.py --read-only
```

Each of the six P01 captures omits the model box, while all eight P03 captures retain a box consistent with the licensed world extents, including the signed negative boss and the positive-X YZ boss. Shared `FrameValues` agrees within the ModelHeader tolerance of `1e-15 m` on each coordinate and radius. Two captures have an exact-bit difference within that tolerance. P03 saves hold geometry-change stamps 103–111 and one cosmetic update entry each. All eight entry keys match the independently saved `ModelStamps` update word and each flag is 1. The separate `ModelStamps` body stamps are 105–121. P01 holds geometry-change stamp 101 and an empty cosmetic table.

All 14 saves carry the same typed hatch profile, with its name, angle and scale as explicit caller settings. The six P01 spans are 263 bytes and end at next index 49. The eight P03 spans are 351 bytes and end at next index 51. The packaged configuration walker lands on exactly the same material pointer and inherited map. The replay digest is `ef3be3962d274b830225cc91c447269c7b946147ec0811fe8364852f69890bdf`. Its rows preserve source digest, exact boundaries, archive counters, typed state and native span digest. Hosted `CheckConfigBody` will compare nongeometry bytes exactly and the frame against measured geometry. Construction continues with the [material and its density parameter](ConfigMaterial.md).
