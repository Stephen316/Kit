# Ordinary blind boss base display return

The 370-byte `moDisplayDim_c` return occupies +14–384 after the favorite tag in the generation-19000 P03 distance display. The research encoders construct three bounded spans totaling 366 bytes. They leave the signed `SelLeader` field at +344–348 outside generation. All offsets below are relative to the favorite class-reference tag. [Favorite and subclass boundaries](DisplayFavorite.md)

The source uses SOLIDWORKS 34.4.1.1011. The `sldmodu.dll` SHA-256 is `2201734ebe0106efde5a93e306067b4b5e2fdb0ba70bf38ce9a59242b283cb99`. The `sldmfcu.dll` SHA-256 is `bea7d36e54929371aa9d6db9faa3210b8661a14038eb1f0fcac714c6d110e9a6`. The archive count serializer is in `swccu.dll` SHA-256 `7254b30f4eb77fd5b49fdbb0a7ab499ba3bf1d39a3f8f18d72090c2568967b49`. The preferred virtual addresses below refer to those builds.

## Mask construction

The binary display serializer writes `Mask2` as an unsigned long at `0x4c82b533`. The field at `+0xb60` starts at `0xfc` from `0x4c887f83`. The feature constructor sets bits 0 and 17 at `0x4c86d8e6–0x4c86d8f7`. It sets bits 14, 21, 22, 23 and 29–31 at `0x4c86d928–0x4c86d940`, clears bit 25 at `0x4c86d955` and stores at `0x4c86d959`. The constructor obtains application toggle `0x387` at `0x4c86d906–0x4c86d90e` and sets or clears bit 8 at `0x4c86d91a–0x4c86d920`. The exported `moDisplayDim_c::isDesignIntent` at `0x4b28d720` reads that bit. The research caller supplies the design-intent preference.

The serializer writes `Mask3` from `+0xb64` at `0x4c82bc5f`. Initialization at `0x4c887f8d` sets `0x1870`. The ordinary feature constructor sets bits 0, 2, 9, 14, 16–19 and clears bits 3 and 8 at `0x4c86d944–0x4c86da37`. Three named settings supply the remaining bits.

| Bit | Source setting | Native link |

| 12 | Apply inward rounding to tolerance | Document dimension definition member `+0x78`, getter `getApplyInwardRngToTol` at `0x3c767f20`. Copied at `0x4c888549–0x4c888559`. |
| 13 | Remove zero | Document dimension definition member `+0x9c`, getter `getIsRemoveZero` at `0x3c763df0`. Copied at `0x4c888561–0x4c888574`. |

The eight saved masks are `0xe0e241fd` and `0x000f4a75`. The explicit settings `design_intent=True`, `inward_tolerance_rounding=False`, `remove_zero=False` and `uppercase_dimension=False` reproduce both words through the native-source bit rules. The archived measurement receipt records model geometry and dimensions. The fixture supplies the four settings explicitly because the measurement receipt omits them. ## Pinned archive boundary

Read-only replay checked all eight native file hashes and the measurement receipt bound by save receipt `f2308ae749f3d739746301873a49e997e2cf494f9d459e954403b66b17e22a94`. The 194-byte prefix was identical at every native cursor with SHA-256 `72c1a1838d6544a33566ff18669c3d60d6cf21e98248498beb4d10ea39707184`. The 136-byte options span SHA-256 is `40a4ee34b3ace06e46b2aa7702f0ca5ed7ef16840b6fabbfe0d596c2311dd88e`. The three generated intervals end at the first override string, the selector and the subclass return respectively. Hosted execution for this extension remains pending.
