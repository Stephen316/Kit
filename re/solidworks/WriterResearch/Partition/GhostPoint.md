# Ordinary part ghost point partition

The generation-19000 P01 archives store an origin-point ghost in the physical sibling stream `Contents/Config-0-GhostPartition`. The native part loader has a missing-stream path which initializes ghost reference state when ghosting is enabled and the manager's suppression bit is clear. All six pinned P01 saves carry manager mode 2, which leaves that bit clear. Licensed P01 reopen, edit and rebuild with the stream omitted remain unmeasured.
