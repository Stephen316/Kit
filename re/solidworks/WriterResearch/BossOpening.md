# Generation 19000 ordinary boss opening

`WriteBossOpen` starts at the rectangle trim return and stops before the first chooser count. It allocates one extrusion and its name using the shared archive map. It takes the emitted profile and trim file, a `ConfigAtomBinding` from the configuration's atom manager, and the boss's name, node flags and inherited feature state. The binding supplies both the native atom ID for the signed list and the separate archive object slot for the transfer pointer. Its body supplies the native feature ID. The returned chooser owner carries the new extrusion slot, feature ID and existing trim file object.
