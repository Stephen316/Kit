# Standalone generation-19000 CMgr composition

[`BuildCmgr`](CmgrComposition.py) composes the complete decompressed `Contents/CMgr` stream for a standalone part with one default configuration and one external object. The part can have a rectangle sketch alone or a sketch with one axis-aligned rectangular blind boss of uniform density. The caller supplies the allocated model state and supported visual profile. The constructor starts one fresh `ArchiveWriter` and retains it from the root definition through the second manager list.
