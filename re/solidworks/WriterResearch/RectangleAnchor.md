# Generation 19000 rectangle Origin coincidence

`WriteRectAnchor` follows the [four axis constraints](RectangleAxes.md) and writes the single live coincidence plus the empty logical groups that precede sketch presentation. The caller supplies the already generated point graph and ordered operands. The external Origin proxy at slot 4 and local corner at slot 0 must both be at the sketch origin. Two new `sgPointHandle` objects preserve their separate identities and ordered relation operands.

The preferred virtual addresses use the installed `34.4.1.1011` `sldmodu.dll` [pin used for the corner writer](RectangleCorners.md).
