# Sketch split ordinals and direction wildcard

The two `sketch_tag_id` uint32 split fields are read as a **one-based fragment ordinal** and a **total fragment count**.
Every split tag in the saved corpus satisfies `1 <= splitSequenceId <= splitTotalNumber`.
The pair `(1,1)` is the unsplit value, not the only valid serialized value.

The [evidence record](SketchSplitSemantics.json) summarizes the corpus study.
The [read-only corpus report](SketchSplitSamples.json) was generated by [SketchSplitSamples.py](SketchSplitSamples.py).
No native calls, production-code execution, or local tests were used for this study.

An earlier version also cited static inspection of installed Fusion libraries.
That material was removed.
The field names, the producer invariant and the matching rules came from it.
The corpus is consistent with the names and the invariant.
They are not confirmed by a black-box experiment.

## Invariant

A semantic codec can reject malformed pairs.
It must not replace real split pairs with `(1,1)`.
It must not treat the corpus's largest observed count as a format limit.

The removed static evidence also described a compatible-match rule that differs from pair equality.
That rule is not confirmed by a black-box experiment.
Kit must not rely on it.

## Corpus evidence

All 712 archives decoded for this sampler, yielding 5,077 sketch tags with no archive failures.
All tags use version 3; secondary IDs and topology role flags are zero in this corpus.

All 84 split tags satisfy the one-based invariant.
The report includes an owning archive, entity, class, field path, and full tag for each nontrivial pair.
It also lists every affected archive.

Direction is also not a Boolean-only domain.
The corpus contains 2,099 zeros, 2,964 ones, and 14 `UINT32_MAX` values.
The persisted direction values are therefore `0`, `1`, and `4294967295`.
Treating `4294967295` as a wildcard came from the removed static evidence.
It is not confirmed by a black-box experiment.

Every secondary uint64 in this corpus is zero.
Kit treats it as the second component of the source-curve key.
That role came from the removed static evidence and is not confirmed by a black-box experiment.
The current corpus supports retaining the existing zero-only secondary profile.
