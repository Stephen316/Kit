### Saved study findings

Study scripts, reports and capture paths in this section are relative to [the Study directory](../Study/README.md).

`pipe-decoding.json` compares six cases in `pipemodes-87cfa7d8d82b`: circular/square/triangular sections, a hollow pipe, a partial open path and a partial closed path. Section type, size, hollow mode, stored thickness and active fractions match the API through explicit numeric bindings. The path resolves through a typed proxy/descriptor/leaf to a sketch ID and curve tag. Native `AgainstDistance` maps to API distance one in these observed cases; `AlongDistance` supplies distance two on the closed circle and holds an inactive copy on the open line. Both roles remain in the output. The API exposes a zero-valued thickness parameter even for these solid pipes, so stored and active thickness are separated. Other operations, composite paths and path-orientation variants remain unsupported.

`sweep-decoding.json` compares eight files in `sweeps-5f87eff25e24`: straight/curved paths, parallel/perpendicular orientation, partial distance, taper, twist, surface and cut. Eleven comparisons per file match API settings, with explicit rectangle-profile membership and sketch line/arc path references. Dynamic attribute framing supports both observed NewBody and Cut prefixes. Parallel sweeps expose null active taper/twist while retaining the native cached values separately. Two earlier circle-profile controls are preserved, and three malformed-control/owner cases are rejected. This earlier stage left composite/closed paths and guides unsupported; the later mode stage below adds observed variants. Bidirectional/solid-body paths, cut-participant topology and swept geometry regeneration remain unsupported.

`loft-decoding.json` checks eight exports across `lofts-838ea6e83e97` and `lofts-03b4a6f1ce2f`: two/three sections, solid/surface, start/end/both Direction controls, unmerged tangent edges and a straight centerline. Typed section records preserve explicit order and selected sketch-profile loop membership. Optional angle/weight bindings make the endpoint-control blocks variable-length; their roles and values match the API. A centerline resolves through an owned sketch-curve reference. The report records 124 supported comparisons, two prior Loft fixtures and three malformed cases. Initial capture errors and their corrected retries are retained. This earlier stage did not identify closure or rails; the later `loft-mode-decoding.json` stage below adds those controls. Other conditions, section types and procedural reconstruction remain unsupported.
