### Saved study findings

Study scripts, reports and capture paths in this section are relative to [the Study directory](../Study/README.md).

`pattern-decoding.json` checks six rectangular patterns with one/two directions, spacing/extent modes and independent symmetry flags. A missing second-axis selection and its stored zero vector remain explicit: Fusion's API may supply a default direction that is not present in that native field. Quantities and distances are reported as parameters, without claiming a complete instance-placement algorithm.

`rectangular-pattern-mode-decoding.json` adds seven exports with explicit body/source-feature inputs, multiple bodies, signed distances, custom axes, sketch-line directions and Optimized/Identical/Adjust compute controls. Owned collection/descriptor/proxy copies establish input identity, and typed direction descriptors agree with independently decoded vectors. Native rectangular element keys follow the observed grid-key encoding; they are retained separately from API element IDs. Six earlier mode cases and six rejection checks pass. The initial suppression setter raises the API's “not yet implemented” error and is excluded from the default generator. No nonempty native-key/API-ID suppression mapping is claimed. `rectangular-suppression-decoding.json` records the alternate `PatternElement.isSuppressed` probe: the first attempt required timeline rollback; the corrected attempt then reached the same API “not yet implemented” error. Both completed with zero exports, and the failures are retained in `rectmodes-f0d529b6e6b0` and `rectmodes-419a3a194fc0`. The local feature-input API exposes no suppression property. No nonempty feature suppression mapping has been established. Main-reader body groups use the explicit `PatternInputBody` role. This stage brought the corpus to 358 archives and 339 classes.

`path-pattern-decoding.json` compares nine files in `pathpatterns-de9857f6a1bc`: spacing/extent, shifted start, flipped direction, symmetry, identical/along-arc orientation, multiple body inputs and one suppressed instance. `circular-pattern-decoding.json` compares eight files in `circularmodes-45f859c1f1b6`: full/signed/symmetric body patterns, suppression, multiple bodies about a custom offset axis and feature patterns with Optimized/Identical/Adjust compute options.
