    def mirror(self, sketchEntities: "list[SketchEntity]", mirrorLine: "Base") -> "list[adsk.fusion.SketchEntity]":
        r"""
        Mirrors the specified sketch entities about a mirror line and returns the newly
        created sketch entities (mirrored input entities together with the auxiliary
        sketch points - line endpoints, arc/ellipse centers, spline fit points, etc. -
        that the mirror operation created). Symmetry constraints are added between each
        original entity and its mirrored counterpart, matching the interactive Mirror
        sketch command.
        When mirrorLine is not a SketchLine that already belongs to this sketch (for
        example, a BRepEdge, BRepFace, ConstructionAxis, or ConstructionPlane), a new
        sketch line is created in the sketch for each call. Existing projections of the
        same source entity are not reused. This matches the behavior of the interactive
        Mirror sketch command. To avoid duplicate projected geometry across repeated
        mirror operations, project the source entity once into the sketch and pass
        the resulting SketchLine as mirrorLine on every call.
        sketchEntities : The sketch entities to mirror. Sketch points and sketch curves are supported.
        All entities must belong to this sketch.
        mirrorLine : 
        <p>The entity that defines the axis of symmetry. The axis itself is always a line in
        the sketch plane. The following entity types are accepted; non-SketchLine inputs
        are projected or intersected internally to obtain that line, matching the interactive Mirror
        sketch command:</p>
        <ul>
        <li>SketchLine belonging to this sketch - used directly.</li>
        <li>Linear BRepEdge - projected into the sketch.</li>
        <li>Planar BRepFace - intersected with the sketch plane.</li>
        <li>ConstructionAxis - projected into the sketch.</li>
        <li>ConstructionPlane - intersected with the sketch plane.</li>
        </ul>
        <p>Any input that does not yield a line in the sketch plane is rejected.</p>
        All sketch entities created by the mirror operation. The first entries are the direct
        mirrors of the supported sketchEntities, in the same order as the input (one per input;
        unsupported entries are skipped). Following those are the auxiliary SketchPoints that
        the mirror operation created - for example, the start and end SketchPoints of mirrored
        SketchLines, which is where the symmetry constraints are attached. The auto-projected
        mirror axis (created when mirrorLine is not a SketchLine) is not included. On error or
        invalid input an empty array is returned.
        """
        return _fusion.Sketch_mirror(self, sketchEntities, mirrorLine)
