# Typed native graphics and complete native-document re-emission

`GraphicsCodec.ReadGraphics(WorldData, MeshStreams)` decodes the qualified Fusion OGS world and its referenced mesh streams into an immutable `GraphicScene`. `EmitGraphics(Scene)` regenerates `GraphicsData.WorldData` and its numbered `MeshStreams` entirely from those semantic values. Production code does not read research artifacts, invoke a CAD runtime, or retain original graphics payloads.

The supported profile includes ordinary and nested worlds, group/geometry/text nodes, class-checked shared object identities, named rendering attributes and text styles. The profile also includes noninstanced position and position/normal/UV buffers, index buffers, BRep and sketch LOD framing, and texture-mapping caches. Float widths, optional-field presence, object identities, mesh allocations, registry order, and custom callback branches are explicit. Every world byte and every referenced mesh byte must be accounted for. Extra bytes, unresolved identities, incompatible classes, overlapping allocations, unknown serializers, and unsupported versions fail.

```python
from convert.formats.Fusion.GraphicsCodec.ReadGraphics import ReadGraphics
from convert.formats.Fusion.GraphicsCodec.EmitGraphics import EmitGraphics
from convert.formats.Fusion.GraphicsCodec.Model.State.GraphicsStream import GraphicsStream

Scene = ReadGraphics(WorldBytes, (GraphicsStream(0, MeshBytes),))
Rebuilt = EmitGraphics(Scene)
```

`DocumentCodec.ReadDocument` and `EmitParsed` now route the exact `OGS.BlobFolder/OGS/DefaultScene/world` and `stream_mesh_NNN` members through this codec. `DocumentModel.Graphics` holds the typed scene or `None`. Container emission creates the complete nested directory chain. Document validation resolves graphics entity references against primary owners in the declared segments. The original ordinary-rectangle control and native-saved authored cuboid can therefore cross the complete document boundary. The crossing includes their entity graphs, BRep histories/snapshots, material packages, configurations, and graphics. Preview images remain explicit image parts.

The native browser vocabulary includes the exact version-zero `VisualAnalysesBrowserEntry` declaration, whose initialized own member set is empty and whose inherited schema was already qualified. It is supplied only as an explicit reading supplement. The accepted independent author's schema vocabulary is unchanged; unknown versions and base mismatches still fail.

Native saved material packages also contain paired appearance instances. Document material validation now resolves an existing base instance to its exact `_Post2015` partner when both exist. It applies this rule before its unchanged role, definition-ID, and library-ID checks. The rule came from binary inspection. Beyond the accepted controls below, it is not confirmed by a black-box experiment. A suffixed-only instance is insufficient, and arbitrary definition matches are not substitutes. Both persisted instance identities and all typed material fields remain intact during emission.

## Scope and evidence

The ordinary rectangle world contains 14,552 bytes, 39 shared objects and an 860-byte mesh stream. The saved cuboid contains 24,382 bytes, 41 shared objects and a 956-byte mesh stream. Independent research decoding accounts for all fields and mesh ranges in both controls. Binary serializer analysis first named some of them; it was removed at the tip. The [wire model](../../../../re/Fusion/Reconstruction/OgsScene/WireModel.md), [compressed-report index](../../../../re/Fusion/Reconstruction/OgsScene/EvidenceIndex.json), and [browser declaration](../../../../re/Fusion/Reconstruction/OgsScene/BrowserSupplement.json) bind the implementation to specific sources and versions.

Unsupported branches remain explicit. The unsupported branches are T-spline, mesh and lattice custom worlds; nonzero cached display-item serializers; multiple populated LODs; and instanced or alternative vertex layouts. The unsupported branches also include nonempty clipping/style/effect links, nonempty paragraph tabs, and ordinary/nonculling sketch-node lists. These are not opaque passthroughs. The admitted registry records `TextureEffectAttribute` version 1 or 2, but its unsupported nonempty callback is not enabled by that declaration.

Black, Ruff, mypy, strict Pyright and repository steering checks passed locally. No local automated tests ran. New remote integration cases cross complete F3D files and require typed read/emission/read equality and exact regenerated graphics members. The cases exercise a semantic text edit and reject trailing world/mesh bytes, unknown registry versions, dangling document-entity links and incompatible material aliases. [Complete native acceptance](../../../../re/Fusion/LocalOracle/NativeDocuments/NativeAcceptance.json) passed for both regenerated archives on Fusion 2706.1.17, alongside their original controls. The ordinary rectangle preserves 347 physical entity records and initial volume 30 cm³. The ordinary rectangle then accepts a height change from 25 to 37 mm and reopens at 44.4 cm³. The saved cuboid preserves 246 records and initial volume 14.467 cm³, then accepts 37 to 43 mm and reopens at 16.813 cm³. Both retain correct mass properties, material/appearance identities and colors, six faces/twelve edges/eight vertices, healthy timeline entries, and rollback/restore behavior. The regenerated input SHA-256 prefixes are `0203674063f5` and `49f92bbe4f33`; [preparation](../../../../re/Fusion/LocalOracle/NativeDocuments/Preparation.json) binds the complete hashes and shows exact byte equality for both regenerated world/mesh pairs. This is native lifecycle acceptance of these complete profiles, not a pixel-level rendering comparison or general OGS support.
