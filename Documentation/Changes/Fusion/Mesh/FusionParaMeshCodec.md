# Typed Fusion ParaMesh codec

`ReadParaMesh(bytes) -> ParaMesh` and `EmitParaMesh(ParaMesh) -> bytes` implement the qualified version-2 `.paramesh` component format under `convert.formats.Fusion.MeshCodec`. The immutable model exposes positions, ordered triangle corners, the original signed terminal corner word, octahedral normal pairs, corner overrides, feature edges and per-triangle face-group keys. Its registry keeps the container UUID, Design `fusion_uuid`, normal resource UUID and face-group UUIDs independent. Stream names and their chunk order are explicit semantic references.

```python
from convert.formats.Fusion.MeshCodec.EmitParaMesh import EmitParaMesh
from convert.formats.Fusion.MeshCodec.ReadParaMesh import ReadParaMesh

mesh = ReadParaMesh(source_member)
rebuilt_member = EmitParaMesh(mesh)
```

The writer constructs the protobuf registry, MessagePack identity table and descriptors, scalar streams, terminal differences, known-length LZMA framing and chunk envelope from the model. The model contains no encoded payloads, compressed blocks or captured file templates. Positions and octahedral pairs are stored as float32; newly supplied Python floats are rounded to that representation. `Geometry.CornerNormal` provides a derived normalized vector for a triangle-corner ordinal without replacing the original octahedral pair.

The admitted registry contains one vertex/corner normal channel with an explicit override stream, one triangle face-group channel, one feature-edge stream and one `fusion_uuid` property. The associated count is qualified at its observed value 1, independently of the number of group mappings. Exactly six named streams have chunk ordinals 2 through 7; their semantic roles come from the registry rather than names such as `v` or `r0`. The version and reserved header, descriptors, channel fields, element codes and compression selector must match the qualified profile. Unknown channels, properties, split components, raw streams, textures and `.tsm` cages reject explicitly.

Input, individual decoded streams and aggregate decoded allocations are bounded at 64 MiB. All references are checked: corner indices and their implied starting value, sorted unique override corner positions, and normal table cardinality. Ascending unique feature edges belonging to actual triangle topology, group membership and stream identities are also checked. Chunk ordering, incomplete messages, trailing input and decompression termination are checked. Registry UUID spellings and group order are retained. Compressed bytes may differ after re-emission; semantic scalar representation is preserved.
