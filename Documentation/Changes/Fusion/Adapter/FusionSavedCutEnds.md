# Saved Fusion blind and through-all Cut

The partial F3D reader projects the one-sided solid Cut's saved end condition after checking the owned profile, historical target, active end operands and repeated dependencies. The archived blind cuts store end code `1` with a negative owned AlongDistance and the saved sketch normal. The typed definition exposes the positive depth and inward direction. The original signed value and Fusion expression remain on the owned parameter referenced by `fusion.extrude.along_parameter_id`. The edited depth is 5 mm. The other blind archives, including the inch-display save, retain 4 mm. [Pinned cut extent evidence](../../Research/Readers/FusionCutExtentEvidence.md)

The through-all cut stores end code `4`, no depth operand and an explicit inward vector. Its own extent-field proxy, descriptor and context trace back to the same historical body as the separate Cut target. The partial reader preserves this association as an `extent_reference` selection. The typed definition has no length or up-to reference. The recorded end flags are retained as native evidence.
