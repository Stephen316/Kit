# Saved Fusion sketch face provenance

The public Fusion partial reader now retains the historical face recipe used by the P04 CutSketch. Read the archive with `open_document(path, strict=False)`. The sketch keeps its measured native basis and its frame links to a `historical_face_recipe` selection. That selection records the native descriptor, proxy, bounded-face recipe, four boundary recipes, and the historical body and creator. [Public Fusion adapter](FusionPublicAdapter.md)

The sketch definition's body backlink and feature-owned face selector must agree with the separately verified Cut target in the same component. The selector names a typed anchor on the same historical body and reciprocates the earlier boss through the support record. Each edge context repeats the descriptor's namespace and names a typed edge recipe in the target body's naming scope. The four context recipes must match all four bounded-face operands after resolving their own name indices, including ordered adjacent faces and vertex operands. [Saved Cut target](FusionCutTargetSelection.md), [Archived source face evidence](../../Research/Readers/FusionCutFaceEvidence.md)

Inspection of eleven pinned P04 archives corroborated all face selectors and 44 boundary contexts. The source recipe is distinct from the similarly named result topology. The partial reader leaves the selection path empty and `fusion.native_support_resolved` false until it resolves the ASM face occurrence. `fusion.native_support_kind` identifies the retained recipe. The sketch frame carries no principal datum identity. Fresh readback, strict regeneration and cross-format edit acceptance remain open.
