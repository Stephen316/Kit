Read the source through `open_document(path, strict=False)`. The feature's attributes now include `fusion.profile_selection_proxy_id` when the saved route is verified. Its source spans retain the proxy alongside the existing feature, descriptor and loop evidence. [Public Fusion adapter](FusionPublicAdapter.md)

The feature owns the forward proxy reference and repeats the proxy and descriptor in its native dependency list. The proxy must select that exact descriptor and reciprocate the feature owner. The descriptor and loop continue to identify the earlier source sketch's selected perimeter. A conflicting reference in one of these witnessed layouts prevents partial profile attachment and produces the existing profile diagnostic. Other feature layouts keep their existing reader paths.
