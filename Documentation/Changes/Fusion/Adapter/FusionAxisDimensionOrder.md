# Saved Fusion axis-dimension operand order

The public Fusion partial reader can project horizontal and vertical point-pair dimensions whose two saved operand lists differ in order or carry nonzero dependency slots. Use `open_document(path, strict=False)` to inspect the resulting sketch relations. The repeated argument list provides the neutral ordered point references, while the original prefix references and slots are retained as `fusion.dimension_dependency_object_ids` and `fusion.dimension_dependency_slots` on the newly resolved relations. [Public Fusion adapter](FusionPublicAdapter.md)

The sketch's owned geometric relation list, then its owned dimension list, provide the independent check for each operand slot. Each slot must equal the number of earlier uses of that same native entity. The route checks the typed member records and their sketch-local operand kinds before accepting that order. The dimension still requires its reciprocal numeric binding, matching expression and driving flags, and agreement between its saved scalar and the magnitude of its ordered axis distance. The original order determines the signed distance multiplier. Other dimension classes retain their existing layout requirements. [Saved dependency slots](../../../Gotchas/Conversion/Fusion/Api/FusionDimensionSlots.md)

Inspection of six P01, eight P03 and eleven P04 pinned archives verified 404 operand slots across these geometric and dimensional lists. In P04, four dimensions per archive reverse the prefix list in their argument list. The YZ control switches axes and changes the sign of the height, cut-height and center-V distances. The historical API independently supplies parameter values, expressions, driving state and measured geometry. Operand IDs, order and slots come from the saved records. [P04 saved rectangle relation evidence](../../Research/Readers/FusionCutSketch/FusionCutRelationEvidence.md), [P04 saved center expressions](../../Research/Readers/FusionCutSketch/FusionCutCenterEvidence.md)

Hosted registry cases compare all six dimension references and their signs across the eleven P04 archives.
