# Refuse stale inline FreeCAD snapshots

Public FreeCAD reads now check the scoped inline extrusion's saved native controls before returning an embedded neutral document. The guard runs before read filtering. It leaves existing specialized extrusion, revolve, datum, spreadsheet and sketch reconciliation in place.

The scope is one active inline `ExtrudeFeature` with Create or omitted operation, one source body, a supported whole-sketch line or circular profile and millimetre geometry. Existing native metadata and retained geometry routes keep their separate contracts. The reader resolves the exact `KitId` feature, base sketch, support plane and body tip. It checks finite forward and reverse distances, direction, symmetry, reversal, solid mode, supported termination and profile placement. Native profile geometry, construction membership and constraint identities, driving state and values must remain unchanged. Geometric object names and types must match the source inventory, including objects carrying native Shape properties. Native end-expression paths and unique local parameter aliases must agree with the source. Equivalent literal unit spellings may retain the same exact physical value.

Expected native controls come from the existing pure XML emitter with the original manifest. This uses its current parameter ownership, unit conversion and default direction rules. It does not launch FreeCAD, load vendor software, publish a replacement file or prefer a native graph over the source's typed identities and metadata.

Genuinely usable meshes and the existing reserved native-document or native-binding payload routes are excluded using the adapter's existing predicates before the inline scope is evaluated. Empty meshes and nonreserved auxiliary or verification notes remain in scope. These exclusions preserve separate existing behavior; they do not establish freshness, qualification or acceptance for those routes. Scoped parameter sheets must satisfy the existing local-cell contract, including exactly one empty `XLinks` record, the local-link flag and no unknown group children.

Changed or ambiguous scoped controls raise an explicit unsupported-edit reconciliation error. Unchanged controls preserve the original neutral graph. This guard does not validate cached BREP contents or prove that every native property agrees with the snapshot. Parameter and shape reconstruction after edits remains unfinished; this guard prevents silent stale success for its checked controls and does not establish complete editable-read support or native acceptance. Manifest-copy and hash failures retain their existing refusal behavior.

The process coverage invokes actual public writes and reads on independently authored line and circular profiles, signed and symmetric ends, omitted Create, a sketch-reference dependency and a constrained rectangle. Authored archive mutations change native end controls, geometry, construction membership and constraint driving state, or add another native Shape owner, while retaining both original neutral snapshots. They check refusal in strict and permissive reads, including filtered reads, and preserve the original bytes. The operator's earlier copies had restored values before saving; they are not a witnessed mismatched native-save control. [Operator evidence](https://github.com/TryUniCAD/Kit/pull/94#issuecomment-6931047492)
