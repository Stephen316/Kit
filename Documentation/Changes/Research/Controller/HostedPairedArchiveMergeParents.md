# Bind the paired archive receipt to the hosted merge parents

The Linux paired archive step records the first parent of the exact GitHub Actions `pull_request` merge commit as its tested base. The `GITHUB_SHA` checkout must be a two-parent merge with the event head as its second parent. The event target must match `GITHUB_BASE_REF`. A different event base is accepted when it is an ancestor of the actual first parent. The workflow blob, checked source tree, archive tests and corpus pins retain their existing checks. [GitHub pull request merge refs](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#how-the-merge-branch-affects-your-workflow)
