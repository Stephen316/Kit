# Retry one refused explicit SOLIDWORKS Cut

The [through-all scope collector](ThroughAllScopeControl.md) checks the selected sketch at mark 0 and each intended solid at mark 1. If the exact selection is verified and `FeatureCut4` returns null for an explicit case, it closes the scratch document and publishes a source-pinned `<mode>.primary_creation_failure.checkpoint.json` before retrying. Selection, COM, cleanup and other errors still end the attempt at their measured stage. [Multibody selection and editing](https://help.solidworks.com/2024/english/api/sldworksapiprogguide/Overview/Programming_Multibody_Parts.htm?id=1.4.39.1)

The single retry rebuilds the same two Boss features and Cut sketch in a fresh document. It creates the ordinary automatic Cut, obtains its definition and reacquires the intended solids while `AccessSelections` holds the model in rollback. It sets `FeatureScope`, clears `AutoSelect`, assigns the exact `FeatureScopeBodies`, and applies `ModifyDefinition`. The collector checks rebuild and feature errors, then reads the fresh feature definition, scoped bodies and measured affected set before saving. The separately launched read-only reopen phase repeats those observations before and after rebuild against the original specification. [Feature scope body property](https://help.solidworks.com/2024/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IExtrudeFeatureData2~FeatureScopeBodies.html) · [ModifyDefinition](https://help.solidworks.com/2021/english/api/sldworksapi/SolidWorks.interop.sldworks~SolidWorks.interop.sldworks.IFeature~ModifyDefinition.html)

Each case records `authoring_route` as `feature_cut4` or `modify_feature_scope`. Recovered cases retain the first null result. A failed retry keeps its own stage and primary error in the private failure receipt. The primary checkpoint holds no native acceptance evidence.

The collector compiled against installed SOLIDWORKS interop `34.4.1.1011` with warnings treated as errors, and Windows PowerShell 5.1 syntax parsing passed. The managed body array, actual policy persistence, and explicit A and A+B geometry still need a licensed Windows run.
