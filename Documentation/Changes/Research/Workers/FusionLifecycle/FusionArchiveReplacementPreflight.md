# Seal one replacement preflight for the archived Fusion timeout

The continuous owner now revalidates the joined archive, original attempt,
and commissioned exit before checking the exact commissioning admission,
installed add-in, physical bundle and reviewed launch provider. It records
one replacement context per archive while holding the existing endpoint
locks and parked controller snapshot. The challenge derives from the
original commissioning challenge and this exact recovery basis, so replay
requires the same bytes. A conflicting preflight or changed deployment
leaves the installation parked.

The report carries the digest of the sealed preflight. A later generation
cannot inherit the old archive binding. The record neither launches Fusion
nor grants claim admission. A later provider must verify the exact fresh
replacement and its main-thread healthy control before a second attempt.

The hosted disposable AppKit and real A03 timeout case checks the retained
preflight, refuses a changed challenge, and invalidates the original
generation through the normal controller. It also checks refusal after a
change to the private commissioning record. The fixture passed at PR head
`2fc4acbd`. [Hosted macOS verification](https://github.com/TryUniCAD/Kit/actions/runs/43806206876/job/133097509508)
