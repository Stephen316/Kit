## From the sketch to its support

The modern profile continuation at `sldmodu+0x9ec8b0` reads chain metadata and count, then loads `moSketchChain_c` at `0x9ecc89`. Its serializer at `0x11363b0` reads both short counted ID lists, scalar fields, the label, empty handle selection and trim objects. A compact body selector at `0x1110e61` and a signed byte count at `0x1111211` frame the embedded kernel packet. That packet advances the outer byte cursor and has its own object storage. The actual body lengths are 1,207 bytes in baseline A and 1,201 in YZ, ending exactly at the independently observed refill bases of 10,906 and 10,970.

The body continuation loads four `moEdgeRef_c` objects through the object array call at `0x9ec2d1`. Their `0xa62a10` serializer shares the typed entity representation reads of the later face reference. Each edge references the supporting cap and three ordered boundary occurrences. The four edges and their nested references close the observed map count from 418 at the sketch pointer to 456 at the support token. The dynamic edge-index array at `0x9c9210` reads element width, allocation fields and count before the four indices. The remaining fields are an empty secondary-body list, an empty contour map with its flags, and a null line-handle pointer. The replay reaches the typed support read at 11,531 and 11,595. The runtime support selector is initialized to 1 in this branch. The source reads a separate u16 selector only when helper bit 1 is present and bit `0x20` is clear.

The component reads the local unit component, the root part and a feature-data record with ID `-1` before allocating the embedded `moRefPlane_c`. Its node, concept, feature and atom serializers lead to the face-plane declaration. The licensed baseline atom probe observes bytes 11,777, 11,801 and 11,889 at `0x9ca3ea`, `0x9cabbc` and `0x113429a`, respectively. The live map remains at next index 459, the owning object is slot 458, and the helper reports generation 19000, context mask zero and state zero. The offline YZ walk reaches 11,841, 11,865 and 11,953 by decoding the same fields. The profile parser checks array guards and the atom rollback branch, which reads an optional null object and three zero dwords after its nonzero selector. Normalized baseline native witness SHA-256 is `00d522c9f5f0cb6e3409139b2ed61286d99ead92f844b6e37a361447f89b7b6e`.

## Source layout

The executable pins are for build `34.4.1.1011`. `moFaceRefPlnData_c` at `sldmodu+0x112e7c0` invokes the geometry loader at `0x1138930`. It reads the point and normal, the optional transform basis, the translation and scale, and optional typed children. Its `moCompFace_c` uses the local unit component and part, the guarded component base, and the modern face read at `0xa63e98`. The enclosing face-plane wrapper repeats the point and normal and ends with the zero outer axis code.

`moFaceRef_c` dispatches its six inline entity IDs through `0xa62f6d`. The selected method at `0xa67e50` reads a typed object at `0xa67f1c`. The surface ID base invokes the embedded reference loader at `0xa67a84`. Its local branch reads a null object at `0xa6859d` and a typed `moFR_c` at `0xa685b2`. The feature reference reads the existing filed object, a signed feature ID and a compact native time word. The filed object establishes the reference context while the feature ID identifies the boss.

`moEndFaceSurfIdRep_c` reads the signed occurrence and one additional dword at `0xa6af81` and `0xa6af8e`. Each subsequent `moFromSktEntSurfIdRep_c` reads one signed boundary index at `0xa69977`. The primary feature ID, time and occurrence begin at face body +46. The corresponding four edge tuples begin at +70, +90, +110 and +130. The last entity pointer is null before the modern trailer. The separately measured supporting cap has occurrence 1, and the opposing cap has occurrence 0.
