# Read the two SOLIDWORKS Bosses before a scoped Cut

The resolved history reader walks both Boss sketches, their saved contour chains and their principal-plane references. Each Boss must refer to its preceding sketch through the archive map. Typed cap and side surfaces bind the actual body, feature, file and clock to a pair of repeated chooser records. The reader preserves the raw partition state, cap classifiers and start token. It leaves the cursor at the following Cut profile. [Scoped history reader](../../../../../src/convert/adapters/solidworks/Resolved/Scope/History.py)

The signed start and depth come from the ordered saved dimension endpoints projected onto the saved support normal. Each projected magnitude must agree with its own driving parameter and both cached copies. The end selector must agree with the signed depth, and the chooser centre must agree with the resulting start and end planes. The offset Boss stores a positive 10 mm start parameter and a positive Z reference vector, while its start endpoints move from Z = 0 to Z = −10 mm. The endpoints preserve that sign.

The three licensed scope saves replayed through this reader and the typed Cut operation. In each save, the Bosses belong to native bodies 101 and 102, features 32 and 40, and support plane feature 2. The read recovered signed start and depth of 0 and +10 mm for A and −10 and +5 mm for B, which match the independently measured before-Cut body bounds. The handoff occurred at resolved-stream byte 18,421 in all three files. The normalized read observation SHA-256 is `e3f84cc573a1f17d3460a203f5a97844f3aa2ba06c480d29aa6ce233af360d56`. The archive replay uses the research Cut sketch and support entrance. Public projection and editable conversion acceptance remain open.
