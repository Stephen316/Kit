# Compare SOLIDWORKS discovery parameter roles

The discovery census compares the complete list of named dimensions in the licensed feature tree with the neutral parameters. It checks the feature owner in each licensed qualified dimension name. For observations with a known driving state, it compares the neutral role with the reopened source. An equation-owned driven dimension has a derived role. A driven dimension without a recorded equation has a reference role. [SOLIDWORKS driving state enumeration](https://help.solidworks.com/2026/English/api/swconst/SOLIDWORKS.Interop.swconst~SOLIDWORKS.Interop.swconst.swDimensionDrivenState_e.html)

Run `python re/automation/SolidworksCensus.py --output /private/SolidworksDiscoveryCensus.json` and inspect `neutral.named_parameter_roster` and the `neutral.dimension.*.parameter_role` comparisons. The independent [P04 attachment replay](SolidWorksLicensedCutDimensions.md) checks measured parameter operands and equation assignment across both native observation phases. The census covers the saved discovery files. Native edits to converted output remain a later acceptance check.
