# Saved SOLIDWORKS P04 outer rectangle and Boss

The P04 rectangle geometry lives in the selected configuration. Its resolved feature points to that exact sketch allocation. The same resolved profile owns the principal plane reference and the closed rectangle trim. The public reader retains the configuration spans for the points, perimeter lines, axis bindings, origin coincidence and both dimension scalars. It retains the resolved-stream span for the datum reference. [Configuration centering dependencies](../SolidWorksCutCentering.md)

The earlier Boss uses the same verified profile and its saved positive blind depth. The typed record enters the public timeline with the existing feature, sketch and parameter identities. This lets the following Cut refer to its saved support and historical body target. [Cut perimeter and face placement](SolidWorksCutFacePlacement.md), [cut operation](SolidWorksCutOperation.md)

Coverage includes the eleven pinned P04 variants. The YZ archive resolves the Right Plane and the rotated local axes. The inch display uses the original metre scalars. The width, height and Boss depth edits preserve the same ownership. Editable native acceptance remains a separate milestone.
