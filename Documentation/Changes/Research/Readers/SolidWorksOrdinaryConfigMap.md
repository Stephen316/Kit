# Packaged SOLIDWORKS configuration map

`ReadOrdinaryMap` reads the native archive allocation map of an ordinary generation-19000 part from its selected configuration buffer. It accepts the generation from the container reader, then checks the stored root generation and both split lengths. The supported configuration stores zero or one body atom and an empty relation manager. The reader returns the shared class and object maps, their next allocation index, and the observed region and pointer fields after reaching the configuration stream end.

The reader uses the native root seed and the same checked archive binding for class declarations, class references and object references. Supported layout resources ship with the Python package. The material continuation includes the two 16-byte fields at `sldmodu+0x10edb2f` and `0x10edb57`, their following words at `0x10edb40` and `0x10edb68`, and the two words at `0x10edbe3` and `0x10edbf4`. [Packaged entry point](../../../../src/convert/adapters/solidworks/Config/OrdinaryMap.py), [native root material evidence](../../../../re/solidworks/records/P04ContextWalk.md), [native atom and split evidence](../../../../re/solidworks/records/P04AtomWalk.md)

The P01/P03 research reports call the packaged map reader directly. The P04 equation-bearing root path remains in research and shares the packaged root fields and model presentation reader. The ordinary map reader rejects equation-bearing configurations and unsupported layout branches. This checkpoint exposes the map to the later resolved-feature reader. [Configuration presentation](SolidWorksConfigPresentation.md), [rectangular evidence commands](SolidWorksRectangularPlaneEvidence.md)

All eight archived report modes reproduced their existing output bytes across the 25 pinned discovery parts. The replay matched all 634 previously licensed presentation pointer triples. The four independently hashed rectangular baseline and YZ buffers reached their full stored lengths with allocation indices 106 for P01 and 111 for P03. An isolated Python process replayed those four buffers using only the extracted wheel built with cached Hatchling 1.32.0. The wheel contained the packaged root layout resource.
