# SOLIDWORKS archive map ownership

The sketch and resolved research cursors share the packaged archive tag rules. A class reference resolves through the class map and creates a new object. An object reference resolves through the object map and keeps its existing index. An inline class definition checks both reserved indices before adding either entry. Null pointers leave both maps and the counter as they were.

The P01, P03 and P04 replay reports retain their recorded digests. In a memory-only control, a definition that would overwrite an existing object was rejected before either map or the cursor changed.
