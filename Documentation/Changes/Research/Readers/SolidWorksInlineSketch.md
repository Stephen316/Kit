# Packaged SOLIDWORKS inline sketch reader

`ReadInlineMut` reads a generation-19000 sketch after its enclosing resolved archive allocates the `sgSketch` object. It checks the saved tag, body start and map ownership, then returns typed local points, line connectivity, dimensions, line-axis relations and point coincidences. The presentation reader checks that each display handle belongs to that sketch and that the region closes over its saved perimeter. The enclosing cursor resumes at the profile's chain-state fields, with support and placement still owned by the profile reader. [Packaged entry point](../../../../src/convert/adapters/solidworks/Sketch/InlineSketch.py), [native geometry evidence](../../../../re/solidworks/records/P04SketchGeometry.md)

The call stages allocations and cursor changes until the whole sketch passes its checked return. It then updates the existing enclosing maps and any pointer trace. A failed read leaves those maps, the byte position, the allocation counter and the trace unchanged. This layout supports the witnessed planar line rectangle, local length dimensions, line-axis relations, coincidence and region branches. [Rectangular evidence](SolidWorksRectangularPlaneEvidence.md), [presentation and region fields](SolidWorksSketchRegionRecords.md)

P01/P03 research uses the same packaged entry point. The P04 research equation reader delegates each sketch body to the shared geometry and presentation modules. The depth display replay also uses the shared scalar and display layout. [Equation and sketch evidence](SolidWorksSketchGeometry.md), [resolved operations](SolidWorksResolvedEntry.md)

An isolated source process matched all 596 licensed sketch-body pointer observations across P01 and P03 baseline A and YZ. Each sketch body spans bytes 5,773–11,360 in those controls. The next allocation index advances from 174 to 229 for P01 and from 179 to 234 for P03. In each control, a changed final sketch collection count was rejected after the geometry and presentation reads, with the original enclosing cursor, maps and trace preserved.

The eight configuration and resolved report modes, both P04 sketch report modes, the P04 face-occurrence report and the P01/P03 operation report with coincidence retained their existing output digests. The four licensed sketch controls also replayed from the extracted wheel using cached Hatchling 1.32.0.
