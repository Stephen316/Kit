# P04 SolidWorks sketch geometry research reader

Run `python re/solidworks/archive/SketchEvidence.py` from the repository root with Git and the repository Python environment available. The command writes a JSON report for all eleven P04 discovery captures. Each row includes the capture and configuration stream hashes, native sketch object index, geometry interval, points in metres, line endpoint indices, native length parameter identities and logical relation targets. It checks every decoded length against the corresponding independently reopened feature measurement.

The reader verifies the fixed capture revision, the receipt digest, the measurement digest, and all eleven native file digests before interpreting their data. It reads the MO 19000 configuration archive with the existing tag, string and layout engine and uses the witnessed native map initialization. The display segment between the two geometry groups uses an exact-build research layout from the native pointer trace, with typed pointer checks, list counts and bounded relative payload widths. A configuration with a different version, a missing reference, an unexpected tag type or an unsupported count fails the read.

The command reached both sketch returns and the enclosing relation manager return in every capture. All 66 decoded lengths matched the reopened measurements, including the width edit from 40 to 44 mm and the height edit from 20 to 24 mm. The baseline A and YZ boundaries match the licensed traces. The reproduced UTF-8 report has SHA-256 `62f3887b7d85347b18cee856e87655b5406dd9f4c616a7a64bc0780980081aaa`. The display layout preserves the map at both returns. The report stops at the relation manager and leaves the final stream handoff, opaque presentation fields, relation discriminators and conversion qualification open.
