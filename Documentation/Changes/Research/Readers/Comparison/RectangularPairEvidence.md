# P01 and P03 paired rectangle evidence

`python re/automation/RectanglePairEvidence.py` reads the P01 and P03 discovery variants from the four Git-pinned SOLIDWORKS and Fusion receipts. Run it from the repository root with Python 3.14 for the Fusion ZIP codec. It uses the public partial Fusion reader, the public SOLIDWORKS reader and the historical application observations with their original lifecycle phases.

The report compares all four authored perimeter edges by both world endpoints and requires a unique, complete correspondence. It verifies the saved sketch frames, the four active axis targets, the Origin anchor and the two driving dimensions against the original archives and measured values. It also retains the native operand order, dimension type, parameter role and units. The Fusion P01 geometry closes while its public loop declaration remains empty. The SOLIDWORKS reader also publishes four inferred endpoint coincidences. These differences remain separate from the matched authored relations. [Fusion P01 loop declaration](../../../../Gotchas/Research/Readers/FusionPrincipalLoopDeclaration.md)

The P03 report additionally follows the stored Fusion profile proxy and descriptor and the SOLIDWORKS profile object reference. It compares their selected edges and signed one-sided blind displacements against their saved parameters and historical body observations. Fusion emits a create operation and SOLIDWORKS emits a join. The report keeps both labels and distinguishes the genuine negative-depth capture from the positive baseline, even though their perimeters coincide.

The replay produced six P01 and eight P03 pairs. All 56 world-edge correspondences passed with a maximum endpoint difference of `7.11e-15 mm`. All 28 size dimensions agreed on magnitude and selected side. The width operand order matched and the height operand order was reversed in every pair. All eight P03 selected profiles and signed displacements matched. The initial report SHA-256 was `8eb38234c8a909d43bfee6730fdfd672f1ac8787d3b90c51009b70bb19660afc`.

The report retains both eligible counterparts and their endpoint deltas in `candidate_links`. The six P01 pairs require zero public bodies, matching both native observations. Each P03 reader returns one solid with the verified `BlindBoss` as its final feature. Both readers' world bounds match the recorded Fusion body bounds, and the public Fusion volume matches its native measurement. The report records unavailable SOLIDWORKS volume and unavailable centroids for both public readers with boundary representations disabled. Measured native values remain visible alongside those gaps.
