# SOLIDWORKS ghost World and attribute rows

A12 can construct the V37 World class descriptor and payload, and the ghost attribute name and body binding for the pinned P01 layout. The kernel descriptor identifies the two previously unknown World counters as `highest_id` and `current_id`. The research codec accepts their interpreted values and caller-owned transport slots. The isolated vertex uses its own Shell reference. [Native sources and independent archive controls](../../../../../re/solidworks/WriterResearch/Partition/GhostPoint.md)

The hosted archive cases compare the constructed spans on six pinned P01 saves. Whole-partition composition, allocator initialization and licensed native acceptance remain open. [Hosted cases](../../../../../tests/Research/Archives/SolidWorksGhostPointTests.py)
