# SOLIDWORKS ghost partition point records

A12 can construct the separate point, isolated vertex and signed ghost ID value records for the pinned generation-19000 P01 SOLIDWORKS ghost partition. Coordinates, graph slots and identifiers are explicit inputs. The six receipt-bound controls establish the physical positions and the native reciprocal references. [Native source and record boundaries](../../../../../re/solidworks/WriterResearch/Partition/GhostPoint.md)
