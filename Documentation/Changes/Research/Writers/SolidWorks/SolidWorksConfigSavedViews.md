# SOLIDWORKS standard configuration views

`WriteSavedViews` writes the ten standard views and the empty feature color table after the environment folder. It computes the camera bases from the installed native angle constants and allocates every view on the shared Config-0 map.

Read-only comparison covered all 14 pinned P01 and P03 saves. The hosted check compares the nonrotation bytes exactly and checks the generated rotations and complete map.
