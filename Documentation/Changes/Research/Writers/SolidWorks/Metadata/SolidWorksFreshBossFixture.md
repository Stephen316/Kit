# Fresh SOLIDWORKS ordinary boss package fixture

`VerifyFreshBoss` authors a neutral Front Plane rectangle with two driving dimensions and an independently owned reversed one-sided blind extrusion. It supplies 38.25 mm width, 22.5 mm height and −7.75 mm depth through the logical projection and typed writer inputs. The same generated Config-0 and ResolvedFeatures states reach the published `BuildOrdinaryPackage` entry point. The verifier packs the part in memory, then inspects it through `SldprtArchive` and the ordinary rectangle reader. The fixture derives its representations from its own input and uses the existing source research for format knowledge. [Verifier](../../../../../../re/solidworks/WriterResearch/VerifyFreshBoss.py)

The verifier checks the signed extent, independent point operands, native feature and dimension identities, the transfer atom alias, world bounds and CMgr mass and centre. It checks the typed Feature, Keyword and Info XML owners, header and active configuration clocks, explicit config, object and PMI keys, compatibility-body name and ownership, and the empty package inventories. The ordinary Keyword encoder currently fixes the authored sketch and boss tree slots at 26 and 34. The fixture allocates those slots explicitly and checks that they match the typed feature and dimension owners. Alternate feature tree IDs need a separate keyword encoder change. [Fresh model inputs](../../../../../../re/solidworks/WriterResearch/BossInput.md) · [Package metadata](SolidWorksFreshPartMetadata.md)

Run `python -B re/solidworks/WriterResearch/VerifyFreshBoss.py --fixture-context FILE` in the hosted Kit environment, or pass `-` for standard input. The context contains `saved_path`, timezone-bearing `created_utc`, the authored `appearance_asset` locator, and version-four `block_id`. It requires `calendar` with `date` and `utc_offset_minutes`, and `license` with `package_code`, `license_type`, `visible_sketches` and `terminal_flag`. Pass `definition` with four `camera` values, `journal` containing `name`, `time` and `state`, and `terminal_value`. The Front view matrix and viewport centre belong to the fixture. Licensed-package classification requires a caller-owned verification context. A synthetic test selection exercises the archive codec only.

`config_exchange` supplies `id` and `created`. `object_exchange` supplies `folder`, the three `planes` UUIDs in Front, Top and Right order, `document`, `created` and an `index_order` permutation. `pmi` supplies three `keys` in width, height and depth order and `created`. These database clocks are naive ISO local wall times with two-second stored precision. `content` supplies `material_name`, `material_id` and `body_visible`. The published package API supplies the serializers for these owners. [Whole-part package binding](../../../../../../re/solidworks/WriterResearch/OrdinaryPackage.py)

The JSON result reports the archive digest and stream count and separates authored inputs from parsed feature IDs, dimensions and bounds. The annotated verifier has passed pinned Mypy, Black AST equality and compilation checks. Hosted execution and native open, edit, rebuild, save and reopen remain separate evidence steps.
