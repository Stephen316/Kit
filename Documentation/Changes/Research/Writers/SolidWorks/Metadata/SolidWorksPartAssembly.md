The ordinary generation-19000 package writer emits 22 members from typed document, configuration and feature state. It packages the linked Config-0 and resolved features, the shared model header and its duplicate, configuration manager and index, definition, fresh version history, and constructed file properties. The manager reuses the actual atom, feature time, body stamp, bounds and density. The index reuses the generated configuration geometry counter. The summary creation timestamp remains a separate caller input because one P01 save differs from the model creation timestamp by one second.

Its existing-DOM save branch files the value under `FileOpenTime` at `0x3c7dabcc`.
