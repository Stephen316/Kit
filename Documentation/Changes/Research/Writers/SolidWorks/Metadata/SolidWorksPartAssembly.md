# Assemble generated SOLIDWORKS part streams

The ordinary generation-19000 package writer emits 25 members from typed document, configuration and feature state. It packages the linked Config-0 and resolved features, the shared model header and its duplicate, configuration manager and index, definition, fresh version history, and constructed file properties. The manager reuses the actual atom, feature time, body stamp, bounds and density. The index reuses the generated configuration geometry counter. The summary creation timestamp remains a separate caller input because one P01 save differs from the model creation timestamp by one second.

Read-only metadata inspection reached all 14 pinned P01 and P03 files. The digest is `211e068e242f0691b59fb2c63980ab8aacbf4cf746ee722f351c8b2a51efb46e`. For P01, the custom-property cut-list pointer is absent. Four P01 files carry a positive resolved open time with a formatted `FileOpenTime` child. The installed native formatter at `sldmfcu.dll` VA `0x3c7dc2b0` divides elapsed seconds by the open count and renders minutes and a two-digit seconds remainder. Its existing-DOM save branch files the value under `FileOpenTime` at `0x3c7dabcc`.

The package derives the feature index creation time and stamp from its generated model header. The current save path determines the model name, and the header's own file title supplies the shared keyword document reference. The keyword constructor uses the generated sketch and Boss names and driving lengths. The measured millimetre and inch display settings produce two-decimal magnitudes. Filename and configuration mismatches, an unsupported display setting, and a contradictory body-summary inventory fail before emitting the package. Other information properties come from typed caller metadata. The package replay reproduced all three new members byte-for-byte in all 14 discovery cases.
