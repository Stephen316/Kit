# SOLIDWORKS configuration exchange database

The ordinary standalone configuration header is a three-page UnQLite database with one value. It holds a compact MessagePack map for the `dmConfigHeader_c` record, configuration `Default`, and configuration ID 0. The measured profile has family-member ID −2 and an empty representation parent. The caller supplies the configuration's UUID and local creation clock. The UnQLite DOS clock stores two-second precision. [Configuration writer](../../../../../../re/solidworks/WriterResearch/PartConfigHeaderDb.py), [UnQLite page writer](../../../../../../re/solidworks/WriterResearch/UnqlitePage.py), [pinned UnQLite 1.1.9 implementation](https://github.com/symisc/unqlite/blob/ddb1687036d207bbfc67b98cb470fe52ddf22f62/unqlite.c)

The writer constructs the database header, linear-hash map and bucket from fields. The one bucket contains a local record with a computed key hash, lengths and free-space boundary. Native padding fills the rest of each page. The six P01 and eight P03 pinned archives match every generated byte. The two unsupported UUID/time controls were refused. The replay SHA-256 is `d44dc07de9695a9f92a33a1c6cccedce9b80e96016c2df568dd43d310a90452a`. [Receipt-pinned replay](../../../../../../re/solidworks/WriterResearch/VerifyConfigHeaderDb.py)

An independent observer built from the pinned UnQLite source opened each of the 42 read-only database members across the same 14 archives. It enumerated one configuration record per header, six records per 3DExperience exchange member, and two P01 or three P03 PMI dimension records. The 3DExperience records include the three datum objects, a selection-set folder, the document and a table of contents. PMI uses its own MessagePack dimension records. Both remaining database schemas require semantic constructors and native validation. The independent library also reopened one newly generated configuration header and recovered its supplied UUID and typed map without changing the file. [UnQLite reader API](https://unqlite.symisc.net/c_api_func.html)
