# Construct saved SolidWorks dimension styles

The generation-19000 writer now reconstructs the ten saved dimension styles for the pinned P01 and P03 profiles. It writes their common presentation, subclass settings and nine separate length formatter objects through the existing archive class. Hosted comparison preserves document units and the linear formatter’s independent previous value.
