# SOLIDWORKS rectangular boss configuration mass

The A12 [research codec](../../../../re/solidworks/WriterResearch/CmgrBossMass.py) constructs the 254-byte generation-19000 CMgr mass record for a single ordinary rectangular boss. The caller supplies certified world-axis bounds in metres, the body count and uniform density in kilograms per cubic metre. The codec derives centroid, volume, area, mass and the centroidal inertia tensor. It supports default calculation options and the world coordinate frame. Assigned mass and coordinate overrides require their own evidence. [Native field provenance](../../../../re/solidworks/WriterResearch/CmgrMiddle.md#default-populated-options-and-frame)

A read-only replay used the eight P03 saves at `466dcb172dfa3803463e07ccde963ba01671d200`. It rebuilt the solid bounds from each typed owned sketch and signed blind extent, compared the perimeter and extent with the independent licensed reopen receipt, and read density from the Definition tail. CMgr stored the same 158-byte option and coordinate wrapper at bytes 1330–1488 in every file, SHA-256 `2e3fc40724bbb867dc41e0340f0b792b83d8b5cdb7254e221473c3ae1d9c73e3`. The following configuration body count was one and the separate accuracy level byte was zero.

The volume and mass matched exactly in this replay. Maximum absolute deltas were `1.74e-18 m` for centroid, `4.34e-19 m²` for area, `4.24e-22 kg·m²` for diagonal moments and `1.77e-22 kg·m²` for off-diagonal moments. The analytical encoder emits zero off-diagonal moments for the aligned cuboid. The saved kernel residuals remain in the readback. The canonical replay evidence digest is `f13a362e86f7a3dd752cb67fbfe8fa2bda9221108e2c2d3d16d395e99f58110e`.
