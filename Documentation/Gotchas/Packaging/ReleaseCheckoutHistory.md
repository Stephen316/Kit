# Release checkout history

The default checkout might appear sufficient to count commits. It fetches one commit, so the count can repeat across releases. Set `fetch-depth: 0` for [package release builds](../../Changes/PackageReleaseVersions.md). See the [checkout documentation](https://github.com/actions/checkout#fetch-all-history-for-all-tags-and-branches).
