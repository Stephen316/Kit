# Commit messages in release notes

The `fuller` Git format looks readable in a terminal. It includes identity headers and indents the message, which GitHub renders as a code block. Use `--format=%B` to pass the unindented subject and body to the release notes. See [Git pretty formats](https://git-scm.com/docs/pretty-formats).
