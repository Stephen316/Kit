# GitHub release tags

A raw commit SHA might appear valid as a tag. GitHub rejects that form. Use `commit-<sha>` as the tag and the full SHA as the title. Download attached archives and matching checksums. Automatic source archives can have different compressed bytes. See [tag restrictions](https://docs.github.com/en/get-started/using-git/dealing-with-special-characters-in-branch-and-tag-names) and [archive guarantees](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives).
