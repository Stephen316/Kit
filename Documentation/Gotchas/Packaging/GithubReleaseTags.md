# GitHub release tags

A raw commit SHA might appear valid as a tag. GitHub rejects that form. A `commit-<sha>` tag is valid, but the releases page then sorts releases by SHA. Use `v<package-version>` as the tag. See [GitHub release order](GithubReleaseOrder.md). Download attached archives and matching checksums. Automatic source archives can have different compressed bytes. See [tag restrictions](https://docs.github.com/en/get-started/using-git/dealing-with-special-characters-in-branch-and-tag-names) and [archive guarantees](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives).
