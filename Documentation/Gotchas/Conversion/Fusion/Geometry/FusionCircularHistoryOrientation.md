# Circular history requires carrier orientation provenance

A saved cylinder and a tapered circular extrusion can have identical 35-record class inventories, pointers, feature tags and kernel journal shape. The cylinder and the extrusion can still use different upper circular carrier orientations. In the controlled taper, the upper ellipse normal is −Z and both incident coedge reversed flags are flipped relative to the cylinder. The native upper closed-edge vertex owner index is two; an independently authored equivalent geometry can use index zero.

Rebuilding from only radius and height normalizes away those fields. Comparing the result against every source scalar then rejects a valid source; skipping the comparison would hide unsupported geometry or broken orientation. Changing only the normal also reverses the boundary without fixing its coedge uses.

The frustum history reader preserves a typed cone frame and two typed rim frames. These include original centimetre coordinates and dimensional vectors, sine/cosine, parameter scale, normals, cap plane bases, edge intervals, seam points, coedge senses and vertex owner indices. The writer serializes these fields directly and checks their geometric consistency. A fresh writer may use a different coherent parameterization, but that is an explicit choice made by omitting the optional source frame.

ASM logical true and false use different tags, 10 and 11. The structural mapper must recognize these as the same Boolean field category while discovering entity correspondence. Requiring identical tags at that stage rejects a valid opposite orientation before its meaning can be decoded. The frustum mapper permits the Boolean tag pair only during structural matching. The frustum mapper then validates and preserves actual senses and performs strict comparison against the fully reconstructed typed records.

Keep geometric kind and journal qualification separate. The corpus has 24 histories with this same initial count. These histories include a Draft feature with archived old geometry and a rolled-back file with different current and maximum state IDs. Their initial geometry resemblance does not authorize accepting unsupported history. The [state-counter correction](FusionHistoryCounters.md) admits distinct current/maximum IDs within the qualified two-state journal; archived revisions remain a separate boundary.
