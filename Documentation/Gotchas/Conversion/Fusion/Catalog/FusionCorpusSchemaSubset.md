# A complete corpus catalog can omit authoring versions

A catalog that decodes every supplied corpus archive does not necessarily contain every schema version used by a separately accepted author. After document reading switched to the corpus catalog alone, remote run `43230314140` rejected authored class `4C835764-5BAB-4421-B5D2-06015BEF6EB2` at version five. Seven authored-document cases failed while the native rectangle Design case passed.

Select exact class/version/base declarations from the union of independently qualified vocabularies. Preserve the corrected native descriptor when both vocabularies declare the same class/version, and add an authoring declaration only when that exact version is missing. Do not retry parsing with guessed versions or replace unknown records with raw payloads.
