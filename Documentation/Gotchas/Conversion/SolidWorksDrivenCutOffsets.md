# Saved cut offsets have driven values

The P04 CutSketch uses active two-point dimension records for both sizes and offsets. The licensed reopen reports the perimeter sizes as driving and the two centering equation targets as driven. The slots and roles therefore need the typed equation owner alongside the saved distance class.

Read the operands in archive order and check the signed local measurement against the stored magnitude. In YZ, the bottom offset runs along negative local X while its cached value stays positive.
