# A rectangle marker can belong to its Origin proxy

The fifth marker in an ordinary generation-19000 rectangle may receive a legacy native geometry classification. The typed record contains the local proxy point used by the saved coincidence. Its `sgPointHandle` identifies the document Origin feature and the point lies at the same world position in the saved principal frame.

Use the enclosing typed point record to preserve the marker's existing neutral ID. Verify the foreign handle and ordered relation operands before exposing the point and coincidence together.
