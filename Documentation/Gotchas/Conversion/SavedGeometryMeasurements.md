# Saved geometry measurements

Opening a candidate might appear to expose geometry from the current feature tree. Saved body geometry can remain until rebuild. Rebuild the unchanged candidate before measuring it. See [oracle measurements](../../Reference/Research/Oracles.md#measurement-sequence).
