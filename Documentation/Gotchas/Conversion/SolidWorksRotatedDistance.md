# A rotated rectangle can reverse a distance operand direction

Rectangle width and height labels can suggest signed local X and Y constraints. The ordinary generation-19000 SOLIDWORKS saves measured here use `sgPntPntDist` for both dimensions. Depending on the saved sketch frame, the same named dimension can run along a different local axis. The YZ height starts at the origin corner and ends along negative local X, with a positive stored length.

Use the saved dimension class and ordered point handles to bind the perimeter endpoint pair. Keep the parameter value unsigned according to that class. [Saved SOLIDWORKS rectangle dimension operands](../../Changes/Research/Readers/SolidWorksPublicSketchDimensions.md)
