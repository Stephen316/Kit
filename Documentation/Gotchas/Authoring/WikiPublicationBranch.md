# Wiki publication branch

Pushing a publication branch might appear to update the live wiki. Only the serving default branch publishes those pages. Identify remote `HEAD` and explicitly push the reviewed revision there. See [wiki publication](../../Publishing.md#publish-an-authorized-revision).
