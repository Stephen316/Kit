# Directory file limit

A folder of small Markdown files might appear exempt from the path rules.
The path check counts direct tracked files, including Markdown.
[The gotcha migration](https://github.com/TryUniCAD/Kit/actions/runs/43175589314/job/131038966505) failed with 43 files under one directory.

Group related pages into focused subdirectories.
Keep each directory within the [repository path limit](../../../.agents/skills/standard-pr-practice/references/Standards/Portable/RepositoryStructure.md).
