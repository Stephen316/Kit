# Wiki initialization

Enabling the wiki might appear to create its Git remote. The remote remains unavailable until the first web page is saved. Initialize that page before cloning the wiki. See [GitHub's procedure](https://docs.github.com/en/communities/documenting-your-project-with-wikis/adding-or-editing-wiki-pages).
