# Workflow permission documentation

A nondefault read-only permission can fail the strict audit even when its purpose seems clear. Use the existing contents permission and public metadata APIs when they provide the required access. See the [permission audit](https://docs.zizmor.sh/audits/#undocumented-permissions).
