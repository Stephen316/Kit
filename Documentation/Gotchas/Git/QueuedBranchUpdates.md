# Queued branch updates

A conflict repair might appear ready for a normal push. GitHub rejects updates while that PR is in the merge queue. During an authorized merge repair, remove only the affected entry before publishing. Verify the new head, every applicable check, and review evidence before queue enrollment. Preserve other entries and their order. See [PR #73](https://github.com/TryUniCAD/Kit/pull/73).
