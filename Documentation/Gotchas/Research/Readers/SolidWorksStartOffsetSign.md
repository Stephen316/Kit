# SOLIDWORKS start offset sign comes from ordered reference points

The offset Boss in the three licensed two-body scope saves has a positive 10 mm start parameter and a positive Z reference vector. Its two ordered start reference points move from Z = 0 to Z = −10 mm. Applying the parameter or reference vector directly would place the Boss on the opposite side of its sketch.

Project the ordered point displacement onto the verified support-plane normal. Check its magnitude against the driving parameter and compare the resulting plane with the starting point of the separate depth display. Keep the start and depth parameters distinct.
