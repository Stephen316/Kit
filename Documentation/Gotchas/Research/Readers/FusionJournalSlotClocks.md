# Fusion P04 journal slot numbers and reused entries

The P04 Design timeline has four features and the mapped kernel journal has three slots. The first stored state integers change between exports whose feature order is identical. Slot `2` references the initial result BODY and a timestamp attribute from the earlier boss view on the same pointer side. Its complete non-header source-chart inventory becomes evident after applying the verified slot-0 alias mapping to its stored ordinals. Direct materialization rejects the mixed-section slot in all eleven captures. Slot `1` also fails materialization because it has no entries. Derive endpoint actors from a qualified BODY pair, reciprocal timestamp ownership in each view, and the feature owner's exact clock copies. Preserve slot numbers, header counters and chain direction as raw structure until corresponding semantics are independently observed.
